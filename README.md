# Scroll
**Scroll** is an intelligent screenshot manager for Android that helps you organize, search, and understand your screenshots using on-device AI.

## Features
- **AI-Powered Analysis**: Automatically classifies and summarizes screenshots using Gemini Flash.
- **Smart Search**: Search your screenshots by content, summary, or tags.
- **Background Sync**: Seamlessly detects and processes new screenshots in real-time.
- **Privacy First**: All data is stored locally on your device.
- **Material You Design**: A beautiful, modern UI that adapts to your device's theme.
- **Customizable**: Choose your preferred AI model and manage API keys.

## Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **Architecture**: MVVM + Clean Architecture
- **Dependency Injection**: Hilt
- **Database**: Room
- **AI**: Google Gemini API
- **Image Loading**: Coil
- **Build System**: Gradle (Kotlin DSL)

## Setup
1. Clone the repository.
2. Open in Android Studio.
3. Sync Gradle project.
4. Run on an Android device or emulator.
5. Enter your Gemini API Key in the app settings.
